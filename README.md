# Nafis Nirob — Developer Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract the folder.
2. Open `index.html` in your browser.
3. Edit the HTML and CSS in a code editor and refresh the browser to see changes.

## Before publishing
- The LinkedIn profile and email links are set. Replace the generic GitHub link with your own profile URL.
- Replace `your-email@example.com` with your email address.
- Make sure project descriptions accurately describe your work.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `nafis-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open repository **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site. The URL will appear on the Pages settings screen.
